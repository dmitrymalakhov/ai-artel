# 企业开放办公区与玻璃会议室 — 场景02

原创俯视角像素风游戏场景。

## 包含内容

- 完整静态场景PNG
- 动态GIF预览与10张源帧
- 无人物动画修复底板
- 53个独立透明RGBA素材
- 每个素材均含场景比例版与高分辨率源图版
- 中英文说明
- 商业使用许可证

## 动画

7名原创人物采用错峰轻微点头循环。身体、椅子、桌子、电脑和设备保持固定。

## 使用建议

快速搭建请使用 `01_SCENE_SCALE_PNG`；需要自行缩放时使用 `02_LARGE_SOURCE_PNG`。缩放像素素材时请使用最近邻插值。
