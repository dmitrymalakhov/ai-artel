# Corporate Open Office & Glass Meeting Room — Scene 02

Premium original top-down pixel-art office scene for games.

## Included

- Static full-scene PNG
- Animated GIF preview and 10 source frames
- Character-free restoration plate
- 53 individual transparent RGBA assets
- Scene-scale and large-source versions of every asset
- English and Chinese documentation
- Commercial-use license

## Animation

Seven original workers use a staggered subtle head-bob loop. Bodies, chairs, desks, computers, and equipment remain fixed.

## Usage

Use `01_SCENE_SCALE_PNG` for quick scene building. Use `02_LARGE_SOURCE_PNG` when you want to resize assets yourself. Scale pixel art with nearest-neighbor filtering.
