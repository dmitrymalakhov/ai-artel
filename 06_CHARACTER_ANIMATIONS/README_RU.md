# Персонажи AI Artel · анимационный набор v3

Дополнение **../07_DOOR_ANIMATIONS** добавляет открытие/закрытие дверей кабинета и переговорной, фон с чистыми проёмами и демонстрацию прохода. Для внедрения дверей передайте агенту обе папки и их AGENT_HANDOFF.md.

7 персонажей, 32 анимации на каждого, 8 кадров в каждой: **1792 кадра / 224 клипа**.

Версия v3 добавляет 896 кадров: сидение, посадку и вставание, работу в дополнительных ракурсах, кофе и разговор сидя, отдых на диване. Все 896 отдельных кадров из v2 сохранены без изменений.

Откройте **index.html** в браузере. Просмотр работает без установки библиотек и без сервера: действия, скорость, покадровый просмотр, тёмный и светлый фон, проверка прозрачности. Для разовых действий повтор включён только в просмотре; в данных они остаются разовыми.

Быстрая демонстрация сидячих действий: **previews/seated-characters.gif** и **previews/seated-characters.mp4**. Основные действия v2 доступны в **previews/all-characters.gif**. Все 32 действия доступны на странице просмотра; там также есть мебель и последовательность «сесть → посидеть → встать».

## Готовые файлы

- **characters/<id>/atlas.png** — прозрачный атлас 1024×4096, 8 столбцов × 32 строки. Первые 16 строк сохраняют прежний порядок.
- **atlas.json** — координаты кадров, длительности и теги; формат JSON Hash совместим с распространёнными загрузчиками атласов.
- **animations.json** — имена клипов, порядок, длительности, цикличность, события.
- **frames/** — 256 отдельных PNG 128×128 для каждого персонажа.
- **strips/** — 32 горизонтальных ленты 1024×128 на персонажа.
- **sprite_frames.tres** — ресурс Godot 4 с 32 анимациями.
- **manifest.json** — общая точка входа для агента.
- **seating.json** — пять типов мест, подходящие действия, точки привязки, порядок посадки и правила занятости.
- **furniture/** — 12 прозрачных объектов из исходного проекта: столы, кресла, диван и компьютерные принадлежности.
- **tools/phaser-loader.mjs** — загрузка и создание анимаций Phaser.
- **sources/** — исходные листы ImageGen, до упаковки.
- **docs/GENERATION_PROMPTS.json** — сохранённые задания генератору.
- **docs/SEATING_GENERATION_PROMPTS.json** — задания для дополнительных поз и отдельно нарисованных переходов.
- **extraction-audit.json** — источник каждого кадра и параметры упаковки.
- **seating-extraction-audit.json** — происхождение новых кадров, масштаб и общие конечные позы переходов.

## Размещение

Одна ячейка: **128×128**. Точка ног: **(64,112)**, нормализованный origin **(0.5,0.875)**. Рост тела примерно 86 пикселей — близок к исходным офисным персонажам. Масштабировать только nearest-neighbor; для стабильного пиксельного изображения использовать целые координаты и предпочтительно целый масштаб.

Ось Y направлена вниз: **down** — лицом к зрителю, **up** — спиной. Ходьба содержит кадры шага; перемещение по миру задаёт игровая логика. Скорость персонажа надо согласовать с длиной шага. Атлас не содержит мебели: стулья и столы подключаются отдельно из исходного пакета.

Для работы сидя точка ног остаётся общей. Дополнительная ориентировочная точка таза — **(64,94)**; её и смещение конкретного кресла следует один раз настроить в целевой сцене. Это стартовая привязка, а не измеренная анатомическая координата. Стол, монитор, спинка и подлокотник должны перекрывать персонажа только там, где это диктует сцена. Монолитные предметы мебели при необходимости разделяются маской на переднюю и заднюю части.

Посадка и вставание нарисованы влево и вправо. Для фронтального или заднего рабочего места используйте боковой переход с коротким поворотом перед началом или после завершения: точный порядок описан в seating.json. Кофе и разговор сидя есть в боковых ракурсах; отдельных задних ракурсов эмоций нет.

Первый и последний кадры переходов используют те же готовые PNG, что позы стоя и сидя. Это гарантирует точные конечные стыки. Остальные кадры переходов нарисованы отдельно встроенным ImageGen, а затем механически упакованы.

Godot: скопировать папку под именем **06_CHARACTER_ANIMATIONS** в корень проекта, подключить ресурс к AnimatedSprite2D, включить фильтр Nearest, задать offset **Vector2(0,-48)** при centered=true, чтобы точка ног совпала с позицией узла. Если путь папки изменён, обновить ext_resource в .tres.

Phaser: поставить pixelArt=true, загрузить файлы через предоставленный модуль, вызвать createCharacterAnimations в create(), затем spawnCharacter. Для привязки к креслу есть placeCharacterAtSeat с настраиваемым смещением. Исполнение в реальном Phaser/Godot-проекте здесь не проверялось, поскольку в репозитории нет игрового приложения. Официальные справочники: [анимации Phaser](https://docs.phaser.io/phaser/concepts/animations), [AnimatedSprite2D Godot](https://docs.godotengine.org/en/stable/classes/class_animatedsprite2d.html), [длительности кадров Godot](https://github.com/godotengine/godot/blob/master/doc/classes/SpriteFrames.xml).

## Источники и стиль

Новая графика нарисована встроенным ImageGen с исходными моделями и сценой в качестве референсов. Внешность, офисная одежда и цветовые роли сохранены; это новая прорисовка, а не побитовое продолжение исходных изображений. У dark_purple восстановлена фиолетовая рубашка из офисной сцены: исходная отдельная модель по ошибке чёрная.

Исходные файлы проекта не заменены. Финальные листы механически разобраны на кадры, уменьшены nearest-neighbor и упакованы. Некоторые исходные листы имеют лишний столбец или ряд; выбранные кадры и корректирующие листы зафиксированы в аудитах. Прямой равномерный разрез файлов sources/ использовать нельзя — для подключения предназначены готовые characters/. Восемь экспортированных кадров в каждом клипе включают общие конечные позы там, где это нужно для стыка переходов.

## Передача агенту

Передайте **всю эту папку** вместе с **AGENT_HANDOFF.md**. Встроенные furniture/ покрывают основные места для сидения. Для интеграции в целый офис передайте также исходные папки 01_STATIC_SCENE, 02_ANIMATION и 03_INDIVIDUAL_TRANSPARENT_ASSETS.

В **AGENT_HANDOFF.md** есть полный справочник всех 32 действий: условия запуска, допустимые места, завершение и следующее состояние. Также описаны выбор направления, сценарии рабочего дня, прерывания, занятость мебели и проверка внедрения. Агент должен прочитать этот файл до подключения анимаций.
